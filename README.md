# 《暗眼》试玩版

Dark Eye playable prototype — a top-down dark arena shooter.

- Pitch-black arena, muzzle flash lights the scene for ~0.9s
- Hit an opponent to borrow their eyes for 3 seconds
- Sonar (E key) is the only non-shooting way to find people — walking makes no sound ripple
- Single player vs 3 AI bots, first to 5 kills

Open `index.html` in a browser to play. PC: WASD to move, mouse to aim and fire.
